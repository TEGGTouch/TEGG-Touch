# 蛋挞现有 UI 配色清单

基线：`main` 的 `2b91464`。UI 分支已完成工具栏 / 弹窗改造，保留本清单中的功能配色；实际效果见 [客户端截图总览](ui-review.html)。
本清单按当前实际创建控件、样式与状态更新方法核对，包括功能内部的整组按钮、字段、标签、列表、切换器和预览。
颜色来源分散在公共常量、窗口局部常量和动态样式中，不能只读取 `core/button_theme.py` 或按变量名称推断。

## 整体定位

用户已明确：**蛋挞是琥珀色，整体视觉基调为橙 / 琥珀。**

代码也有直接依据：`views/profile_manager_dialog.py` 的 `VIEW_OUTLINE_COLOR = "#F59E0B"` 注释写明“跟项目主色 amber 一致”。
方案当前项、应用、复制确认、命名确认、启动、透明度、关于标题和更新版本等位置已经使用琥珀色。

改造后的共同外壳、标题标记、产品识别和通用导航使用琥珀基调；功能内容沿用各自的配色。
最新确认操作统一琥珀：保存、确定、应用等。功能内部的动作、参数、Tag、取色预览继续保留各自含义。
最新工具栏方案入口改灰、模式高亮与两条滑轨填充改琥珀，轮盘用勾选表示；弹窗功能色仍沿用清单。外框 12 px、内控件 6 px、卡片 8 px、Tag / Checkbox 3 px；输入框内已填按键值也按 Tag 处理。

基础灰色按距离约定为三层：槽 / 未填充滑轨 `#202020`，工具栏 / 弹窗表面 `#2D2D2D`，普通按钮 `#3A3A3A`。最小化和设置使用按钮层，悬停提亮至 `#505050`。分隔线、文字和拖动点的灰色用于边界及对比，不增加基础表面层级。

弹窗所有输入面也属于深灰凹面；横向分类与互斥选项采用深灰槽 / 琥珀滑动高亮。下文的功能清单包含改造前的原始颜色盘点，最新确认按钮与横向切换规则以本段及 [改造记录](ui-redesign-plan.md) 为准。

## 改造时遵循的规则

1. 共同外壳体现琥珀品牌，方角、细线、排版与留白统一；内部保留每个功能和状态的既有颜色。
2. 不以统一主按钮样式覆盖所有保存：键盘映射琥珀、语音绿、轮盘样式玫红、普通编辑器蓝。
3. 候选按键普通状态保持中性；Tab、焦点、Tag、动作类型和状态按原窗口取色。
4. 颜色参数分为品牌、功能、动作、类别、状态和中性基础，避免一个 `ACCENT` 覆盖全部。
5. 样式迁移同时检查静态样式、状态更新和调用方传参，保留常态/悬停/选中/禁用的区别。
6. 方案详情摘要颜色差异、旧语音组件和轮盘未使用的蓝色保存常量单独记录；实际当前控件优先。
7. 图案/预览保持原样；现有语音波形反馈不套公共装饰规则。方角要求只应用到本次允许改造的界面部件。

这份清单指导 UI 改造，不代表当前分支已经迁移了这些窗口。
