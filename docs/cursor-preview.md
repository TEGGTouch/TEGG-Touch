# 0.5.2-preview.1：自动兼容锁光标游戏

本地测试版，尚未正式发布。目标是让已经正常的游戏继续沿用系统光标，在游戏持续把鼠标锁在中心时，自动改用蛋挞自己的逻辑光标。没有新增开关，不需要按游戏选择兼容方式。

## 实现边界

- 正常情况下仍读取系统坐标；只有持续相对移动与中心锁定同时成立时，才接管蛋挞光标。排除静止、短暂抖动、屏幕边缘和绝对定位设备等情况。
- 光标绘制、圆盘悬浮、摇杆、方向盘、点击、侧键、滚轮和回中使用同一坐标源。接管期间回中只移动蛋挞光标，不调用系统回中来与游戏争抢。
- 游戏释放鼠标、打开菜单或切换窗口时自动回到系统坐标；切换时释放旧坐标下仍按住的动作。
- 只旁听 Windows Raw Input，不注入游戏、不拦截游戏读取鼠标、不强制解锁或抢占焦点。游戏相机仍可能响应同一次物理移动，这不是“屏蔽视角”功能。
- 移除第三种“不穿透”和 F11 入口，保留 F9 完全穿透、F10 智能穿透。旧“不穿透”配置读取时回退为完全穿透，其他布局保留。
- 修正空白点击转发后延迟恢复旧穿透状态的问题。

## 如何对照测试

将整个测试包解压到新文件夹，退出旧版后启动其中的 TEGGTouch.exe，不要只复制 exe，也不要覆盖旧版目录。若需原有布局，可在测试版中导入原方案的副本；保留旧版与原始配置用于对照。

1. 黑神话悟空：使用原本正常的布局，检查光标、圆盘、回中和菜单操作是否与旧版一致。
2. 我的世界、使命召唤、星穹铁道：进入实际游戏操作界面，持续移动鼠标，检查蛋挞光标能否离开中央并触发圆盘/摇杆。识别需要一小段持续移动，不会在鼠标静止时接管。
3. 打开/关闭游戏菜单、Alt+Tab、按 F12 退出运行，检查是否自动恢复、是否有按键松不开或误触发。
4. 若有异常，导出调试日志并注明游戏、全屏/无边框/窗口模式、鼠标或其他输入设备，以及发生问题的大致时间。

新增日志包含“自动光标切换”和限频“光标诊断”，可区分 Raw Input 无数据、未识别锁定、错误切换及坐标偏移；旧日志没有这些信息。

## 验证状态

自动化测试覆盖检测状态机及真实 Qt 场景中的光标、悬浮、摇杆、侧键、滚轮、回中和穿透模式迁移；输入注入均被模拟，不会操作桌面或游戏。另做原生 Raw Input 注册/停止和界面初始化检查。

上述检查不能代替实机游戏验证。本测试版尚未确认所有游戏、鼠标驱动、反作弊环境及显示设置的兼容性。
