# 蛋挞弹窗布局规划

本稿记录已落地的 UI 布局，不修改客户端功能。目标屏幕最低为 **1920×1080**；尺寸均指 Qt 逻辑像素，按实际可用屏幕区域约束。
琥珀品牌基调、12 px 圆角外壳与 [现有功能配色](ui-color-inventory.md) 一并保留。

内部按钮 / 输入框 6 px、内容卡片 8 px；滑块拖动点为直径 16 px 的正圆，原功能填充色不变。

## 所有窗口共用的骨架

```text
┌────────────────────────────────────────────────────────────┐
│ 琥珀标记  窗口标题                                      ×  │ 64，固定
├────────────────────────────────────────────────────────────┤
│                                                            │
│  内容：字段 / 列表 / 候选动作 / 参数 / 原有预览               │ 按内容滚动
│  多栏窗口按栏滚动，编辑内容与候选动作互不牵动                 │
│                                                            │
├────────────────────────────────────────────────────────────┤
│ 次要操作 / 现有状态             复制     删除       保存     │ 72，固定
└────────────────────────────────────────────────────────────┘
```

- 标题栏 64 高，左右内边距 24；标题约 20 px，关闭按钮 40×40，位置统一。关闭仍连接该窗口原有的 `reject`、`close` 或 `accept`，不统一改为保存或取消。
- 底栏 72 高，内边距 16×24；操作只排**一整行**，按钮 40 高，最小宽度约 96，按钮间距 8–12。主操作在最右，复制 / 删除靠近主操作；其他已有操作靠左。
- 底栏不是“整行铺满按钮”。右侧动作紧凑成组，中间留白；减少跨窗口寻找保存位置的成本。
- 只移动既有按钮，不补齐不存在的复制、删除、保存或取消。列表项的编辑 / 删除 / 导出、宏步骤的删除、宏候选管理等，仍是内容操作，保留在对象旁边，避免改变其目标或确认行为。
- 顶部和底部放在最外层布局，不进入 `QScrollArea`；底栏高度不随空状态、列表长度、验证提示或候选 Tab 改变。
- 中间使用纵向滚动，常规尺寸不出现水平滚动条。单栏使用一个内容滚动区；双栏 / 三栏各自滚动，避免把整窗放进一个大滚动区后再嵌套多个滚动区。
- 内容栏的组标题、候选 Tab 可以放在栏内的滚动区上方；只有长表单、列表、候选网格滚动。鼠标在哪一栏，滚轮就作用于哪一栏。
- 单行字段约 40–42 高；长 Tag 允许按现有组件规则增高，行标签顶端对齐。长说明靠近相关参数，行间距 8–12，组间距 20–24。
- 分区靠标题、间距和细线表达；不使用大面积彩色卡片、切角或密集描边。表单色点、焦点框、Tag、选中态继续用当前功能色。
- 无内容的空状态仍保留标题、底栏及现有禁用条件，说明放在对应内容区。

## 1920×1080 与 Windows 缩放

主编辑窗口推荐默认高度 820：标题 64 + 内容 684 + 底栏 72。复杂内容通过滚动浏览，操作区始终可见。
不再把所有大窗口固定为 960 高。主窗口采用少量宽度规格，内容简单的弹窗按任务减小尺寸，组件样式保持一致。

正式布局用窗口所在屏幕的 `availableGeometry()`，包括 Windows 缩放和任务栏影响：

```text
实际宽度 = min(该窗口推荐宽度, 可用屏幕宽度 - 64)
实际高度 = min(该窗口推荐高度, 可用屏幕高度 - 64)
内容高度 = 实际高度 - 64 - 72
```

1920×1080 的物理分辨率在 150% 缩放下约为 1280×720 逻辑像素；还要扣除任务栏。
此时 1280 宽的窗口需要收紧到约 1216 或更小，高度也收紧，标题 / 底栏和 40 高按钮保持，中间可见行数减少。
100% / 125% / 150% 都要用实际 Qt 字体与屏幕工作区验证；不能只根据物理分辨率写死 1920×1080。

默认限制宽度最大 1280，避免字段和候选面板被拉得过散；位置沿用现有居中 / 父窗口定位规则。
本轮无需增加“用户拖动窗口边缘调尺寸”的新交互。

## 按钮编辑器：让功能更好读

按钮编辑器已有左侧滚动和五类候选，难读的主要原因是标题层级弱、悬停参数集中在上半部、操作按钮占据左侧下方。
采用更宽的双栏与整行底栏，保留可直接扫描的字段结构。

```text
编辑按钮                                                     ×
──────────────────────────────────────────────────────────────
左：配置（约 500）                    右：候选（约 550）
01 基本信息                           键盘 / 手柄 / 鼠标 / 宏 / 应用
   按钮名称                           当前目标：悬停时 · 蓝色

02 悬停行为                           常用键 / 字母 / 数字 / 功能键
   [悬停触发] [悬停开关]               ↓ 候选按各自现有分类滚动
   当前行为说明
   悬停时 / 开关按键 [Tag ...]
   触发延迟 / 释放延迟 / 触发间隔

03 鼠标按键
   左键 [Tag ...]  右键 [Tag ...]
   中键 / 侧键1 / 侧键2

04 鼠标滚轮
   向上 [Tag ...]  向下 [Tag ...]
↓ 仅此栏滚动，不把右侧候选带走
──────────────────────────────────────────────────────────────
                                     复制按钮  删除    保存
```

实际表单仍优先**每行一个动作**，让长 Tag 有空间；图中左 / 右键并列仅表达分类，不要求挤进同一行。

- 基本信息、悬停行为、鼠标按键、鼠标滚轮是四个可见标题；不新增折叠“高级”区，也不把未配置字段藏掉。
- 悬停触发 / 悬停开关继续使用现有互斥模式，显示原来对应的三个时间参数。按同样行高对齐标签、滑块、数值，说明就近显示。
- 鼠标按键五项与滚轮两项分成两个小组，避免七个不同动作混成一长列；动作色点与 Tag 沿用原映射。
- 右侧“当前目标”是当前聚焦字段的视觉提示，可从已有 `_focus_widget` 状态派生，不是新的选择控件；复用其动作色帮助用户看清按键会填到哪里。
- 候选顶部保留五类 Tab 和原有提示，下面的现有键位分类滚动。不新增候选搜索、推荐键或新的分类数据。
- 画布上的按钮 / 轮盘 / 回中带，以及弹窗内的原有控件预览绘制保持原样。

## 各复杂窗口的阅读顺序

- **键盘映射**：先选列表项，再捕获来源键，再填目标动作，最后选按住 / 点击 / 开关与条目启用。总开关与条目开关清楚分开，来源录制状态继续琥珀提示。
- **语音**：先看识别设备与语言，再选指令，再改口令与按键 / 回中行为，最后测试。测试读取当前编辑内容的原行为保留；结果窗口与设置窗口的生命周期保持原样。
- **宏**：名称 → 步骤序列 → 选中步骤的动作 / 延迟 → 右侧候选。新增指令 / 延迟与保存依次在底栏成组，保存最右；步骤删除仍在每行，不能被误认为删除整个宏。
- **摇杆**：名称 / 摇杆身份 → 当前模拟或 WASD 模式 → 死区、释放阈值、灵敏度 / 方向键 → 鼠标动作。保持现有模式对应字段及八方向条件。
- **方向盘**：保留已有轻松 / 复杂入口。复杂页按方向盘通用参数 → 原预览 → LT / RT 控制组织；目标工作区内 LT / RT 保持并排，整体纵向滚动。互斥错误提示贴近相关组，保存禁用语义不变。
- **方案**：左侧当前激活与当前查看仍是两种状态；右侧看详情，底栏应用当前查看方案。点击列表不自动应用，行内动作仍按原对象执行。
- **设置**：保留快捷键、光标、按钮配色、语言、诊断、关于六个导航页。右侧候选只在快捷键页出现；其余页用原有表单与预览，不因隐藏候选改变外壳或导航位置。

## 底栏按页面与状态复用

整行底栏复用同一个容器，动作可依据原页面 / 状态显示和禁用，固定容器高度。
例如设置的快捷键页把原恢复默认 / 保存移到底栏；光标与按钮配色页把原页面保存移动到底栏，但每组重置仍紧挨其预览。
语言页不添加保存，诊断 / 关于页保留原即刻动作。方向盘“其他鼠标按键配置”和语音“测试指令”继续是原有子窗口入口。
安装、更新、诊断导出的按钮显示与关闭行为由原状态控制，不为了统一组件开放运行中关闭。

## 落地与验收

1. 先做公共 `DialogShell`（标题 / 内容槽 / 整行底栏）与字体、输入、按钮、滚动条样式，允许传入现有功能色。
2. 先迁移按钮编辑和回中带，验证复制 / 删除 / 保存迁到底栏后仍针对原对象；再迁移语音 / 映射 / 宏的三栏或双栏。
3. 最后迁移摇杆、方向盘、方案、设置及全部子窗 / 状态窗。既有候选面板接口、信号与 Tag 焦点链不重写。
4. 每个窗口检查标题 / 关闭位置一致，底栏单行且始终可见，只有内容滚动；内容长短、空状态、无设备和验证错误都覆盖。
5. 在 1920×1080 的 Windows 100% / 125% / 150% 缩放检查中英文、长名称、长 Tag、32 步宏、多映射 / 多语音 / 多方案。不能横向裁切，不缩小点击区。
6. 对照源代码的回调、保存时机、取消、复制、删除禁用和原确认步骤逐项检查。实际客户端验证前，网页样板仅证明视觉结构。
