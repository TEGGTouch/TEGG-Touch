# 蛋挞 UI 改造方案

本轮交付为设计方案与独立视觉稿，尚未修改客户端界面或功能代码。

## 分支与基线

- 分支：`feature/ui-inputegg`，基于本地 `main`，基线提交 `2b91464`。
- 独立工作目录：`D:\VibeCoding\TEGGTouch\TEGGTouch-UI`。
- 原目录继续停留在 `feature/mouse-input-isolation`，保留现有工作。
- 本轮不推送、合并或发布。

## 已确认的边界

允许修改编辑/运行工具栏、全部编辑弹窗及其内部按钮的视觉和布局。
游戏画布上的操作按钮、轮盘、回中带保持原样；手柄操作控件、虚拟光标、软键盘也不纳入本轮改造。
轮盘和回中带的**编辑窗口**可以改外观，画布上的实体和预览中的控件绘制保持原样。

功能保持现有行为：所有入口、字段、单位、取值范围、默认值、快捷键、触发方式、保存时机、确认步骤和禁用条件均保留。
维持现有中英文语言选择，中文优先按当前文案显示；不把中文标签统一替换成英文。
不增加功能、额外确认步骤、主题切换或新的配置项。
工具栏、弹窗及内部控件统一方角，不使用切角；画布操作控件的现有形状保持原样。
蛋挞的整体视觉基调为橙 / 琥珀；共同外壳与产品识别围绕琥珀色设计，内部保留既有动作、功能和状态配色。

## 参考依据与当前问题

参考 inpuTEGG 桌面端 `host/inputegg/style.py` 和 `host/inputegg/ui.py` 中的细线、清晰标题、表单间距和页脚组织。
蛋挞使用方角，沿用自身配色及悬浮在游戏上的产品形态。

从当前代码可确认：

1. 编辑工具栏已经是两行，运行工具栏是单行；值得保留，再调整分组、间距和层级。
2. 颜色已经承担动作、功能及状态的区分。样式直接写在多个控件内部，需要统一尺寸、边框和布局，同时保留既有颜色对应关系。
3. 按钮编辑器已有“左侧字段、右侧候选动作”的双栏，设置已有侧边导航；这些结构符合任务，可以继续使用。
4. 按钮编辑器、设置和方向盘编辑器高度固定为 960；较小屏幕和高 DPI 下存在内容超出可用区域的风险。
5. `core/button_theme.py` 专门管理画布操作控件配色，必须与此次工具栏/弹窗主题隔离。

## 蛋挞现有配色体系

完整盘点见 [UI 配色清单](ui-color-inventory.md)，涵盖各功能内部的按钮组、Tag、候选 Tab、列表、参数、子弹窗与动态状态。
代码 `views/profile_manager_dialog.py` 已明确注释琥珀色“跟项目主色 amber 一致”。

### 品牌基调与功能配色

共同外壳使用琥珀 `#F59E0B` 和深琥珀 `#D97706`，配深灰底和浅色文字。
功能内部按当前整套配色保留：键盘映射琥珀、语音绿色、方案琥珀、轮盘样式玫红、宏指令紫/延迟琥珀、手柄参数蓝。
普通按钮编辑器保存仍为蓝色，语音保存为绿色，键盘映射保存为琥珀，轮盘样式确定为玫红；不按“主按钮”统一染色。
共同外壳的品牌标记与内部功能色并存。

### 动作颜色：编辑字段与运行反馈对应

`core/constants.py` 的 `ACTION_COLORS` 明确标注“按钮编辑器 + 触控按钮状态共用”。
按钮编辑器、摇杆编辑器、方向盘鼠标键编辑器按字段取色；`scene/touch_button_item.py`、`scene/wheel_sector_item.py`、`scene/wheel_ring_item.py` 的运行状态表沿用同一组动作色。
方向盘的鼠标动作中心反馈也读取 `ACTION_COLORS`。

| 动作 | 颜色 | 色值 |
| --- | --- | --- |
| 悬停 / 悬停开关 | 蓝 | `#0284C7` |
| 左键 | 琥珀 | `#F59E0B` |
| 右键 | 绿 | `#10B981` |
| 中键 | 紫 | `#A855F7` |
| 滚轮向上 | 粉 | `#EC4899` |
| 滚轮向下 | 玫红 | `#F43F5E` |
| 侧键 1 | 青 | `#06B6D4` |
| 侧键 2 | 紫罗兰 | `#8B5CF6` |

名称字段沿用琥珀；悬停延迟等普通延迟字段沿用 `C_DELAY` 蓝。
保留字段色点、标签底色与聚焦边框的动作色，不将它们全部替换成统一强调色。

### 操作控件：按类别区分，按方案可调

`core/button_theme.py` 将按键/中心轮盘、手柄/摇杆、回中带分为三组。
默认基色分别为灰 `#555555`、蓝 `#3B82F6`、深绿 `#176F2C`；方向盘另外使用自己的蓝色基色。
每组从基色派生填充、边框和文字色，保留用户保存的自定义颜色；触发反馈色与阈值色独立于类别基色。
这些画布控件及预览的绘制不在此次改造中修改。

### 功能与状态：按原上下文保留

- 编辑工具栏：方案/模拟模式为深蓝，启动与透明度为琥珀，缩放为绿，轮盘启用为玫红。
- 键盘映射：琥珀；宏名称/指令步骤：紫罗兰，宏延迟步骤：琥珀。
- 语音的指令列表、新建、保存、行为卡/动作选择和候选 Tab 用绿；输出按键 Tag 仍为琥珀，语音测试波形与 HUD 为青色。
- 方案的当前项、查看边框、应用、命名及复制确认用琥珀；行内图标随当前项反色；详情 Tab 选中仍为蓝。
- 轮盘样式编辑的选中卡、显示勾选和确定用玫红，环切分选中用粉红；重置/取消中性。手柄方向盘参数蓝，LT 浮标玫红、RT 浮标琥珀。
- 运行工具栏：语音/回中开启为深绿；完全穿透 ON 为灰，智能穿透 OFF 为蓝；停止为暗红。光标/显隐主要以图标区分，悬浮球激活为琥珀。
- 设置的 `HOTKEY_COLORS` 是另一组功能识别色：映射琥珀、光标青绿、悬浮球紫、语音绿、回中深绿、软键盘蓝、停止红，穿透按 ON 灰 / OFF 蓝区分。
- 相同色相在不同上下文可以承担不同职责，不据此重新映射既有功能；保留各处原有区别。

## 视觉规范

| 元素 | 建议 | 用途 |
| --- | --- | --- |
| 背景 | `#202020` / `#2D2D2D` | 深灰背景与工具栏/弹窗外壳 |
| 输入与次级块 | `#3A3A3A` / `#404040` | 输入框、字段区、标签与列表 |
| 边框 | `#444444` / `#555555` | 1 px 分隔与可操作控件边界 |
| 主文字 | `#E0E0E0` / `#FFFFFF` | 字段、标题与操作文案 |
| 次要文字 | `#AAAAAA` | 提示与单位，保证深底可读 |
| 品牌基调 | `#F59E0B` / `#D97706` | 共同外壳、标题标记、产品识别，围绕琥珀设计 |
| 功能内操作 | 按原窗口的琥珀 / 绿 / 玫红 / 蓝等 | 每套按钮、列表、Tag 和状态保持其上下文颜色 |
| 动作/功能/状态色 | 依原字段或上下文 | 沿用上述映射；启动继续琥珀，保存继续蓝 |
| 形状 | 方角矩形 | 工具栏、弹窗、按钮、输入框均无切角 |
| 字体 | 微软雅黑 UI + Bahnschrift | 中文正文 14–16，标题 20–22；英文/数字适当使用 Bahnschrift |
| 间距 | 4 / 8 / 12 / 16 / 24 | 字段内部紧凑，分组之间留白 |

普通按钮采用深灰细框，动作标签、色点、焦点与必要状态继续使用现有配色；用留白、字号和分区减少拥挤。
启动用琥珀；普通编辑器保存用蓝，语音保存用绿，键盘映射保存用琥珀，轮盘样式确定用玫红。
删除/停止维持各窗口现有状态色，关闭按钮常态为中性。共同外壳不添加渐变或装饰阴影；现有语音波形反馈的同色系渐变保持其用途。
启用、关闭、选中、禁用等状态同时用文字、图标或边框表达，维持现有状态区别。
视觉可以纤细，常用点击区域仍保持约 40–44 个逻辑像素；焦点与悬停清楚可见。

## 编辑工具栏

继续底部悬浮、可拖动、两行布局。

```text
拖拽 | 当前方案 | 创建：按键 / 回中带 / 轮盘 | 辅助：语音 / 软键盘 / 键盘映射 | 启动 | 最小化 / 设置 / 关闭
     | 模拟模式：键盘或手柄               | 透明度滑块 + 数值 | 场景缩放滑块 + 数值
```

- 使用细线和留白区分组别，方案和启动具有明确层级；上方的模式标记为文字，不增加切换入口。
- 键盘/手柄模式仍按现有机制显示相应创建按钮，保留所有入口。
- 滑块统一形态与数值对齐，范围保持透明度 10–90%、缩放 50–200%。
- 普通尺寸两行；较窄屏幕允许把**完整按钮组**排到下一行，不缩小点击区域、不塞入新增菜单。
- 保持工具栏定位、拖动、最小化及软键盘位置同步。

## 运行工具栏

继续底部悬浮，以单行为默认布局，和编辑模式共用同一外壳。

```text
拖拽 | 当前方案 · 运行中 | 光标 / 悬浮球 | 语音 / 回中 / 显隐 / 软键盘 | 穿透状态 | 停止
```

- 保留所有现有按钮与快捷键提示，不增加二级菜单或额外点击。
- 普通操作沿用中性色；按既有逻辑显示深绿、琥珀等状态色，保留已有文案与图标。
- 穿透和停止维持独立且明确的状态语义，停止始终在最右侧直接可见。
- 保留悬浮球的外观、展开/收起行为和保存位置；仅工具栏本体改视觉。
- 窄屏按组换行；不调整自动隐藏、穿透、焦点和鼠标输入行为。

## 编辑弹窗

统一“标题区 → 内容区 → 固定操作区”。标题、分组标题、说明、字段、单位按层级区分。
保留每种窗口已有操作集合：原来没有保存/取消的窗口，不添加保存/取消按钮。
关闭仍遵循原来的 `reject`/关闭行为，复制、删除、保存仍连接原回调。

| 窗口 | 布局方向 | 保留事项 |
| --- | --- | --- |
| 按钮、轮盘扇区编辑 | 左侧名称/悬停/鼠标触发，右侧候选动作，底部操作条 | 五类候选动作、标签输入和轮盘项不能删除的条件 |
| 键盘映射 | 左侧来源/目标与映射列表，右侧候选动作 | 选中字段、组合键、映射开关 |
| 宏编辑 | 左侧名称/步骤/时间参数，右侧候选动作 | 步骤顺序、添加/录制/删除/保存和混合宏行为 |
| 手柄摇杆、方向盘、方向盘鼠标键编辑 | 保留现有模式导航和参数分区 | 灵敏度、阈值、模式条件与实时预览绘制 |
| 回中带编辑 | 简洁单栏，目标选择与说明分区 | 现有目标选择、保存/复制/删除，无新增参数 |
| 轮盘样式选择 | 保留样式候选与预览区 | 各样式、参数及预览原有绘制 |
| 语音设置与语音测试 | 指令列表、参数和测试分区 | 麦克风/语言、测试/识别状态、宏/应用/回中候选 |
| 方案管理与复制 | 列表层级更清晰，统一选中态及行操作 | 新建、命名、复制、重命名、删除、导入/导出和已有预览 |
| 设置 | 保留六项侧边导航，右侧表单/候选区对齐 | 快捷键、光标、按钮配色、语言、诊断、关于的全部原有选项 |
| 命名、确认、消息、语音分块大小等子弹窗 | 同一外壳的紧凑版本 | 原验证与确认行为 |

“按钮配色”设置页只统一表单外观，色值、派生规则和控件预览维持原样。
更新、更新后说明、驱动安装、诊断导出和独立关于窗口列入第二轮外壳统一，避免它们继续使用旧风格；下载/安装/导出逻辑保持原样。
系统文件选择窗口沿用系统样式。

### 尺寸与可读性

- 先按窗口任务设置合适的默认大小，再按当前屏幕 `availableGeometry` 约束窗口尺寸。
- 标题和操作区保持可见，较长字段/步骤/候选列表使用现有滚动结构，必要时补齐内容滚动。
- 不靠缩小字号把全部内容强行塞进窗口。
- 尺寸调整涉及现有固定宽度与自绘组件，分窗口完成；预览、选区和实际游戏控件尺寸不随表单重排改变。

## 实施顺序

1. **视觉样板**：先定编辑工具栏、运行工具栏、按钮编辑器和设置的统一观感。当前 `ui-redesign-preview.html` 是独立评审稿，只展示代表性内容。
2. **公共视觉基础**：新增 `views/ui_theme.py`、`views/ui_components.py`，集中颜色/字体/间距与窗口外壳、标题、分组、页脚样式。颜色按品牌、功能、动作、类别、状态和中性基础分别命名，组件允许传入功能色；样式只挂到指定工具栏和弹窗容器。
3. **工具栏落地**：迁移编辑/运行工具栏的背景、按钮和滑块；保留原信号、状态更新、拖动/定位方法。
4. **主编辑器迁移**：迁移按钮、宏、键盘映射、手柄编辑器及共享候选面板，再处理语音、方案、设置、轮盘与回中带编辑。
5. **子弹窗与外围窗口**：统一命名/确认/消息框及更新/驱动/诊断窗口，逐一检查独立样式和动态状态更新。
6. **验证和评审**：同一配置截取改造前后画面，确认视觉与功能边界，再进行后续合并/发布流程。

### 代码边界

- 主要修改 `views/edit_toolbar.py`、`views/run_toolbar.py`、`views/*_dialog.py` 和弹窗共享的 `views/app_palette.py`、`views/recenter_palette.py`。
- 现有候选动作面板、`TagInput` 和图标字体检测已有跨窗口引用，逐步迁移样式，保留调用接口；避免一次性重写业务结构。
- 不全局设置 `QApplication` 样式，不修改 `core/constants.py` 中共享的画布颜色，不修改 `core/button_theme.py`。
- `scene/`、`engine/`、输入处理、方案结构、配置读写与 `views/overlay_window.py` 的模式切换/信号连接保持原样。
- 不调整窗口标志、置顶、模态、焦点策略、鼠标穿透、自绘命中区或光标机制；外壳使用普通方角矩形。

## 验收

- 先审查 diff：功能/配置模块与画布操作控件没有改动。
- 对工具栏逐个检查既有信号、模式切换后的入口、快捷键/状态提示、悬浮球收起展开与位置恢复。
- 对编辑器用现有样例配置检查保存、复制、删除、取消/关闭和禁用状态，与改造前保持一致。
- 在 1366×768、1920×1080、2560×1440，以及 Windows 100%/125%/150% 缩放下检查关键窗口，覆盖中文和英文；所有操作区可达、文案不重叠。
- 用相同方案对比游戏操作按钮、轮盘、回中带及手柄控件的前后截图，确认绘制与命中区域未变。
- 逐项核对动作字段、运行反馈、工具栏状态与设置功能色；完全穿透 ON 仍为灰，智能穿透 OFF 仍为蓝。
- 按配色清单核对各功能内部的整组按钮、选中列表、Tag、Tab、参数和预览，覆盖键盘、语音、方案、轮盘等窗口。
- 跑与受影响窗口有关的现有测试，特别是 UI 指针/更新窗口测试；最终检查使用真实 Windows Qt 环境。
