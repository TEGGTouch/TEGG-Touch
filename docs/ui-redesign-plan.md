# 蛋挞 UI 改造方案

本轮已在 `feature/ui-inputegg` 落地 PyQt6 客户端 UI 改版，并通过原入口运行。
查看 [真实客户端截图总览](ui-review.html)，其中工具栏与按钮编辑器包含运行中截图；其余为实际 Qt 窗口的视觉盘点。

## 最新工具栏与圆角修订

- 工具栏外框 12 px，内部按钮 / 输入 6 px，内容卡片 8 px；滑轨 3 px、拖动点为 16 px 正圆。
- 去掉编辑工具栏左侧黄条和所有工具栏按钮描边；方案入口改灰底、文档图标，固定 240 px。
- 透明度与缩放滑轨加长，填充与数值均为琥珀；保留原范围与缩放吸附规则。
- “添加模拟组件”下方采用深灰槽内的琥珀滑动选择，等原驱动检查确认后更新。
- 恢复添加按键 / 回中带 / 手柄键 / 摇杆的大加号。中心轮盘与方向盘保留单例显隐，用空框 / 琥珀勾选表达。
- 所有组件、语音、软键盘打开 / 隐藏与键盘映射采用键盘映射的相同宽度（中文 108 px）；软键盘与启动间补充分隔线，启动分配余量。
- 所有主 / 子弹窗更新内部圆角和圆形滑块，保留内容滚动、固定标题 / 底栏及原功能颜色。

- 槽 / 凹面最远：`#202020`，用于键盘 / 手柄模式槽和所有编辑表单滑轨的未填充部分。

- 普通按钮更近：`#3A3A3A`，最小化、设置与其余工具栏灰按钮同层；悬停统一 `#505050`。
- 透明度与缩放填充保持琥珀，圆形拖动点保持浅色；内部表单滑块保留各功能填充色。
- 启动上方新增右对齐的“蛋挞 v0.5.2”，版本取自 `APP_VERSION`，英文界面显示 `TEGG Touch`。
- 新增 3 px 小圆角等级：按键值 Tag、候选按键、状态标签和 Checkbox；输入框外壳与普通按钮仍为 6 px，卡片 8 px，外框 12 px，滑块拖动点为正圆。

- 18 项 UI 行为测试和 23 项指针路由测试分别运行；新增检查原页面切换、插入目标、禁用原因、单选鼠标 / 键盘互斥与动态宏行。工具栏动画检查等待完成信号，避免机器忙时固定延时提前断言。

## 已确认的边界

允许修改编辑/运行工具栏、全部编辑弹窗及其内部按钮的视觉和布局。
游戏画布上的操作按钮、轮盘、回中带保持原样；手柄操作控件、虚拟光标、软键盘也不纳入本轮改造。
轮盘和回中带的**编辑窗口**可以改外观，画布上的实体和预览中的控件绘制保持原样。

功能保持现有行为：所有入口、字段、单位、取值范围、默认值、快捷键、触发方式、保存时机、确认步骤和禁用条件均保留。
维持现有中英文语言选择，中文优先按当前文案显示；不把中文标签统一替换成英文。
不增加功能、额外确认步骤、主题切换或新的配置项。
按最新反馈采用分层圆角：外框 12 px、按钮与输入框 6 px、内容卡片 8 px、Tag 与 Checkbox 3 px；不使用切角。所有表单滑块拖动点为直径 16 px 的正圆；画布控件形状保持原样。
蛋挞的整体视觉基调为橙 / 琥珀；共同外壳与产品识别围绕琥珀色设计，内部保留既有动作、功能和状态配色。

## 参考依据与当前问题

参考 inpuTEGG 桌面端 `host/inputegg/style.py` 和 `host/inputegg/ui.py` 中的细线、清晰标题、表单间距和页脚组织。
蛋挞使用适度圆角，沿用自身配色及悬浮在游戏上的产品形态。

从当前代码可确认：

1. 编辑工具栏当前是两行，运行工具栏是单行；编辑区按本轮要求改为“方案操作行 + 分组标题行 + 分组控件行”，运行区继续单行。
2. 颜色已经承担动作、功能及状态的区分。样式直接写在多个控件内部，需要统一尺寸、边框和布局，同时保留既有颜色对应关系。
3. 按钮编辑器已有“左侧字段、右侧候选动作”的双栏，设置已有侧边导航；这些结构符合任务，可以继续使用。
4. 按钮编辑器、设置和方向盘编辑器高度固定为 960；较小屏幕和高 DPI 下存在内容超出可用区域的风险。
5. `core/button_theme.py` 专门管理画布操作控件配色，必须与此次工具栏/弹窗主题隔离。

### 操作控件：按类别区分，按方案可调

`core/button_theme.py` 将按键/中心轮盘、手柄/摇杆、回中带分为三组。
默认基色分别为灰 `#555555`、蓝 `#3B82F6`、深绿 `#176F2C`；方向盘另外使用自己的蓝色基色。
每组从基色派生填充、边框和文字色，保留用户保存的自定义颜色；触发反馈色与阈值色独立于类别基色。
这些画布控件及预览的绘制不在此次改造中修改。

### 功能与状态：按原上下文保留

- 编辑工具栏按最新反馈：方案与组件按钮为无描边灰底，模式切换为深灰槽与琥珀滑动高亮；透明度与缩放都填充琥珀。轮盘入口以空框 / 琥珀勾选表示显隐；启动琥珀。
- 键盘映射：琥珀；宏名称/指令步骤：紫罗兰，宏延迟步骤：琥珀。
- 语音的指令列表、新建、保存、行为卡/动作选择和候选 Tab 用绿；输出按键 Tag 仍为琥珀，语音测试波形与 HUD 为青色。
- 方案的当前项、查看边框、应用、命名及复制确认用琥珀；行内图标随当前项反色；详情 Tab 使用深灰槽 / 琥珀滑动高亮。
- 轮盘样式编辑的选中卡与显示勾选保持玫红，环切分选中和确定改琥珀；重置/取消中性。手柄方向盘参数蓝，LT 浮标玫红、RT 浮标琥珀。
- 运行工具栏：语音/回中开启为深绿；完全穿透 ON 为灰，智能穿透 OFF 为蓝；停止为暗红。光标/显隐主要以图标区分，悬浮球激活为琥珀。
- 设置的 `HOTKEY_COLORS` 是另一组功能识别色：映射琥珀、光标青绿、悬浮球紫、语音绿、回中深绿、软键盘蓝、停止红，穿透按 ON 灰 / OFF 蓝区分。
- 相同色相在不同上下文可以承担不同职责，不据此重新映射既有功能；保留各处原有区别。

## 编辑工具栏

继续底部悬浮、整体可拖动。默认三行：第一行管理当前方案与窗口；下面两行横向划分三个功能组，再加独立的启动按钮。

```text
⠿  [文档 当前方案 ▾]  透明度 ━━━━━●━━ 75%  缩放 ━━━●━━━━ 100%  [─] [⚙] [×]
   添加模拟组件                                                 语音控制       软键盘
   [键盘 | 手柄]  [＋按键] [＋回中带] [中心轮盘]              [语音]         [打开/隐藏] [键盘映射]     [▶ 启动]

   切换后，只替换模拟模式组内的三个控件：
   [键盘 | 手柄]  [＋手柄键] [＋摇杆] [方向盘]                其余分组及右侧窗口控制位置不变
```

### 第一行：方案与操作

- 方案选择器固定 240 px，灰底与文档图标兼容键盘 / 手柄。省下的空间均分给透明度与缩放滑轨；完整长名称保留在悬停提示。
- 名称单行显示；超长部分省略，悬停显示完整名称。点击仍打开现有方案管理窗口，不把它改为输入框。
- 透明度与缩放从第二行移至第一行，标签、滑块、数值排在同一行。范围仍为透明度 10–90%、缩放 50–200%，示意值为 75% / 100%。
- 最小化、设置、关闭保持当前相对顺序，固定在右端；不随名称长度、模拟模式切换或软键盘显隐移动。设置入口继续打开原设置窗口。

### 下方两行：三组并排 + 启动

| 组 | 标题行 | 控件行 | 布局约束 |
| --- | --- | --- | --- |
| 模拟模式 | 添加模拟组件 | 槽内滑动切换 + 对应的三个创建/轮盘按钮 | 两种模式占用同一宽度，不挤动后面的组 |
| 语音 | 语音控制 | 现有“语音”入口 | 弹窗内分清编辑、识别设置、测试 |
| 键盘辅助 | 软键盘 | 打开 / 隐藏切换 + 键盘映射 | 两个独立入口；手柄模式下继续保留 |
| 启动 | 留空 | 琥珀色启动按钮 | 始终在最右端，与控件行对齐 |

- 键盘 / 手柄处于同一个深灰槽内，单个琥珀高亮块左右滑动。仍由原覆盖窗口与驱动检查确认后更新显示，保持原切换语义。
- 样板模拟模式组宽 468 px，紧凑视图为 432 px；每种尺寸下，两套控件宽度相同。正式 Qt 布局按两种模式、当前语言及字体的较大 `sizeHint` 预留空间，并给三枚对应按钮统一槽位。
- 双段切换只替代原菜单展示方式。仍由外部 `sim_mode_change_requested` 决定能否切换，手柄驱动检查通过后再调用 `set_sim_mode` 更新选中项和按钮；不能点一下就先显示手柄已启用。
- 当前键盘入口是“按键 / 回中带 / 中心轮盘”，手柄入口是“手柄键 / 摇杆 / 方向盘”。沿用这些名称和行为，不增加新的轮盘或按键类型。
- 软键盘的“打开 / 隐藏”是一个按钮的两种显示状态，仍连接现有显隐动作；正式界面须以真实软键盘可见性同步文字，不能仅在按钮点击时本地翻转。键盘映射继续独立打开现有编辑窗口。
- 标题行字号约 12–13，控件行点击高度 40；细分隔线和留白区分组别，启动不增加标题或说明行。
- 中文常规宽度 1070，英文根据键盘映射文案取 1114 逻辑像素；两种模式均高 157。目标屏幕及高缩放工作区内保持完整三行与所有入口。

### 拖动与位置

- 保留左侧拖动把手，以及工具栏背景/空白区域的拖动；整条工具栏一起移动。
- 按钮、双段切换、滑块等交互控件消费自己的鼠标事件，操作它们不会拖动窗口。
- 保持现有屏幕边缘保护和 `moved` 通知，拖动时软键盘位置继续同步。
- `set_sim_mode` 更新滑动高亮与对应按钮，不重置用户拖动位置；两种模式保留同一宽度。首次显示仍按当前默认位置定位。
- 置顶、不激活窗口、最小化和输入焦点策略保持原样。

### 语音入口的取舍

建议工具栏保留一个“语音”入口，弹窗内部将识别设置与测试入口分区；“测试指令”继续打开现有测试子窗口。

| 方案 | 使用体验 | 结论 |
| --- | --- | --- |
| 工具栏两个按钮：语音设置 / 语音测试 | 测试少一次点击，但工具栏入口变多；直接测试需要明确读取已保存方案还是未保存编辑内容 | 当前不采用 |
| 一个入口，弹窗内设置 / 测试两个标签页 | 顶层简洁，但切页遮住指令编辑内容；把测试嵌入同一窗口涉及引擎与窗口生命周期调整 | 当前不采用 |
| 一个入口，弹窗内识别设置区 + 明确的测试按钮 | 当前指令、设备、语言都在眼前，编辑后直接测试，保留已有工作流 | 推荐 |

语音弹窗布局：上方识别设置带放麦克风、识别语言、运行时启用语音和现有识别延迟“设置”入口；右侧单独显示“语音测试 / 测试指令”。下方保留指令列表、指令编辑、候选动作三栏。
测试使用当前正在编辑的指令、所选麦克风和语言，与现有 `_on_test_commands` 一致；测试子窗口仍由语音设置窗口管理和清理。不给测试动作增加保存前提，也不把测试启动改为运行模式的语音开关。
语音设置、新建、行为选择、测试及保存继续用绿色；输出按键 Tag 琥珀，测试波形青色；普通设置按钮中性。

## 运行工具栏

继续底部悬浮，以单行为默认布局，和编辑模式共用同一外壳。

```text
拖拽 | 当前方案 · 运行中 | 光标 / 悬浮球 | 语音 / 回中 / 显隐 / 软键盘 | 穿透状态 | 停止
```

- 保留所有现有按钮与快捷键提示，不增加二级菜单或额外点击。
- 普通操作沿用中性色；按既有逻辑显示深绿、琥珀等状态色，保留已有文案与图标。
- 穿透和停止维持独立且明确的状态语义，停止始终在最右侧直接可见。
- 保留悬浮球的外观、展开/收起行为和保存位置；仅工具栏本体改视觉。
- 窄屏按组换行；不调整自动隐藏、穿透、焦点和鼠标输入行为。

## 实施顺序

1. **视觉样板**：先定编辑工具栏、运行工具栏、按钮编辑器和设置的统一观感。当前 `ui-redesign-preview.html` 是独立评审稿，只展示代表性内容。
2. **公共视觉基础**：新增 `views/ui_components.py`，统一窗口外壳、标题、分组、页脚和滚动区。沿用各窗口原有功能色，不重写颜色体系；样式只挂到指定工具栏和弹窗容器。
3. **工具栏落地**：迁移编辑/运行工具栏的背景、按钮和滑块；保留原信号、状态更新、拖动/定位方法。
4. **主编辑器迁移**：迁移按钮、宏、键盘映射、手柄编辑器及共享候选面板，再处理语音、方案、设置、轮盘与回中带编辑。
5. **子弹窗与外围窗口**：统一命名/确认/消息框及更新/驱动/诊断窗口，逐一检查独立样式和动态状态更新。
6. **验证和评审**：同一配置截取改造前后画面，确认视觉与功能边界，再进行后续合并/发布流程。
