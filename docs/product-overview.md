# TEGGTouch 蛋挞 — 产品说明

> 面向单手 / 手部受限用户的 Windows 免费开源鼠标键盘替代工具

---

## 一、使用方法

### 整体思路

蛋挞在屏幕上覆盖一层透明交互层，让你**只用鼠标**完成原本需要键盘 + 鼠标的所有操作。核心组件是：

- **中心轮盘**：鼠标向 8 个扇区滑动，触发对应的方向键 / WASD；
- **悬浮按键**：自由放置在屏幕任意位置，鼠标悬停或点击触发按键；
- **回中带**：触碰屏幕边缘区域自动将鼠标吸回屏幕中心，解决单手视角旋转问题。

### 上手步骤

1. 以**管理员权限**运行 `TEGGTouch.exe`（软件需要 SendInput 权限模拟按键）；
2. 在编辑界面按需放置悬浮按键、调整轮盘布局；
3. 为当前游戏**新建方案**，导入或手动配置按键映射；
4. 点击**运行**，进入透明覆盖层，开始游戏；
5. 按 `F12` 随时退出运行模式，回到编辑界面调整。

### 三态穿透模式

| 模式 | 行为 |
|------|------|
| 穿透 ON | 所有点击穿过覆盖层直达游戏 |
| 智能穿透 | 按键区域拦截，空白区域穿透 |
| 阻断 | 覆盖层完全拦截所有输入 |

默认快捷键 `F9 / F10 / F11` 分别切换三种模式，所有快捷键均可在设置中自定义。

### 常用快捷键（默认）

| 键 | 功能 |
|----|------|
| F3 | 显示 / 隐藏虚拟光标 |
| F4 | 收起工具栏 / 展开悬浮球 |
| F5 | 开关语音识别 |
| F6 | 开关自动回中 |
| F7 | 显示 / 隐藏悬浮按键 |
| F8 | 打开软键盘 |
| F12 | 退出运行模式 |

### 方案管理

每款游戏独立保存一个**方案**，包含按键布局、轮盘位置、手柄映射、语音命令、全局参数。方案支持导入 / 导出，也可从已有方案复制并按类别（键盘 / 手柄 / 语音）选择性粘贴。

## 二、手柄支持

蛋挞通过 **ViGEmBus** 虚拟 Xbox 360 手柄驱动，将鼠标动作转换为手柄信号，适合仅支持手柄输入的游戏。

### 三种手柄控件

**手柄按钮（gp_button）**
- 映射到 A / B / X / Y / LB / RB / LT / RT / 方向键 / L3 / R3 / Start / Back 等任意手柄键；
- 可放置在屏幕任意位置，与普通悬浮按键使用方式相同。

**虚拟摇杆（gp_stick）**
- 在屏幕上划定一个圆形交互区，鼠标位置映射为摇杆方向与强度；
- 支持配置死区、灵敏度曲线、8 向锁定；
- 也支持 **WASD 模式**：将 8 个扇区分别映射为方向键，适合不需要模拟量的游戏。

**方向盘（gp_wheel）**
- 鼠标水平移动 → 左右转向（LT / RT）；
- 鼠标垂直移动 → 油门；
- 鼠标左键 → 刹车；
- **Easy 模式**：全屏作为转向区，自动回正，无需精确定位圆形区域。

### 驱动管理

软件内置 ViGEmBus 驱动状态检测，自动识别"已就绪 / 需安装 / 需更新 / 已损坏 / 需重启"五种状态，并提供引导安装对话框，无需手动操作注册表。

## 三、语音支持

### 完全离线识别

蛋挞的语音功能基于 **Vosk** 引擎，**无需联网，无需云服务**，隐私安全。

- 支持**中文（普通话）** 和 **英语**，可按方案切换；
- 模型体积约 40–50 MB，首次使用时下载到本地；
- 识别延迟约 50–150 ms，接近实时响应。

### 语音指令绑定

- 在方案中预设若干短语（如「跳跃」「蹲下」「开枪」）；
- Vosk 仅在这些词表中识别，大幅提升准确率，减少误触发；
- 每条语音指令可触发：**按键 / 宏 / 启动应用 / 鼠标回中**。

### Agent 自然语言入口（即将推出）

唤醒词**「蛋挞」**触发自由语音输入，由云端 AI 助手接管理解与执行（详见第四节）。

### 使用提示

- `F5` 快捷键随时开关语音识别；
- 工具栏绿色波形图标亮起表示正在监听；
- 在**语音测试**对话框中可查看实时波形与识别日志；
- 如未安装麦克风或依赖库，语音功能自动隐藏，不影响其他功能正常使用。

## 四、未来规划 — Agent 助手

### 目标

让蛋挞不只是「按键工具」，而是一个**能听懂自然语言、帮你配置方案、甚至操作电脑**的智能助手。

### 当前状态（Phase 0 已完成）

- **AI 配置助手**：Agent 已可通过工具调用读写方案参数，支持自然语言修改按键绑定；
- **执行层**：键盘 / 鼠标 / 手柄 / 宏 / 启动应用 / 回中 统一接入 `ActionService`，Agent 与运行模式共用同一套执行协议；
- **安全层**：危险词检测（删除 / 关闭 / 购买 / 格式化）触发二次确认，防止误操作；
- **语音唤醒**：说出「蛋挞」→ 自由说出需求 → Agent 解析并执行，无需打字。

### 近期规划（Phase 1）

- **方案自动生成**：输入游戏名，Agent 自动搜索并生成推荐按键布局；
- **语境感知调整**：Agent 读取当前方案，提出优化建议（如「你的跳跃键放在左侧可能更省力」）；
- **多轮对话配置**：像聊天一样调整方案，无需打开编辑界面。

### 中期规划（Phase 2）

- **视觉辅助操作**：Agent 结合屏幕截图，理解游戏界面并辅助执行复杂操作（如自动识别背包格位、地图坐标）；
- **跨应用指令**：控制蛋挞之外的其他窗口，辅助完成游戏内外的任务流；
- **个性化学习**：根据使用习惯自动调整灵敏度、回中速度、语音词表。

### 长期愿景（Phase 3+）

- 成为**无障碍 AI 操作层**：让任何行动能力受限的用户都能流畅使用 PC，蛋挞作为统一的人机交互中间件，连接用户意图与计算机操作；
- 开放 Agent 插件协议，支持社区扩展自定义工具与技能。
